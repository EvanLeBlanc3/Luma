LELUMA · VERSION 1.4.0

Your light.
Your look.

Smoother live filters, easy favorites, and a simpler GitHub upload. The app includes 75 looks plus Original, skin softening, Definition, portrait/landscape framing, and private offline editing.

Update through GitHub — no folders to upload

  1. Download and unzip LeLuma-iPhone.zip. Open its LeLuma folder. You will see 27 individual files.
  2. Open your existing GitHub repository. Select Add file → Upload files → Choose your files.
  3. In the file picker, open the unpacked LeLuma folder and select all 27 files. On a Mac, use Command+A. Upload the selected files to the repository root and commit the changes to the branch used by Pages. The index.html file belongs directly at the repository root. Do not upload the ZIP itself.
  4. Wait for GitHub Pages to finish deploying. Your existing repository name and published URL can stay the same.
  5. Save any photo still open in the old app. Open your published HTTPS address in iPhone Safari while online. Reload and check Help → LeLuma 1.4.0.
  6. If the old version persists, use Help → Repair app / refresh installed version, then tap its refresh button. It may still show the previous name. Reopen and confirm version 1.4.0.
There are no icons or thumbnails subfolders in this download. The thumbnails are embedded and the icon files are at the top level. Old folders already in your repository can remain; this release does not rely on them.

The previous package had 102 files. GitHub's browser uploader accepts up to 100 per upload, so uploading the whole old package at once could fail. This package contains 27 files. GitHub's upload instructions.

Save your favorite looks

  1. Select any look, then tap ★ Favorite beside Looks and Adjust.
  2. The button changes to Favorited. Open ★ Favorites, which stays visible beside the categories, to find your saved looks.
  3. Tap Favorited again to remove a look. Your choices, count, and selected Favorites category stay saved on this device between visits while its website data remains.

Smoother live preview

The live preview uses hardware acceleration where available and follows incoming camera frames, targeting up to 30 frames per second. It avoids a backlog of older frames. Preview detail reduces automatically if rendering is expensive; the saved photo still uses the full source dimensions.

If graphics acceleration is unavailable, LeLuma uses a smaller compatibility preview, which may update more slowly. Show camera only displays the direct feed and applies your chosen look after capture. Show live filters switches back.

If playback pauses, tap Resume video. If neither view moves, tap Restart camera. For further diagnosis, use Help → Camera details → Copy details and send that text with your published app link. It includes renderer and frame-rate information, not photos.

First installation

  1. Create a repository at github.com/new and upload all 27 files at its root.
  2. Open Settings → Pages → Deploy from a branch → main → / (root) → Save.
  3. After deployment, open the exact published HTTPS URL in iPhone Safari. Use Share → Add to Home Screen and name it LeLuma. Enable Open as Web App if shown.
  4. Open the app online once and wait for Offline ready. Tap Open camera and allow camera access.

Choose your frame

Full frame preserves the whole image. Portrait 3:4 and Landscape 4:3 choose a center crop without stretching or upscaling. You can change framing after capture. Controls remain upright; use iPhone Control Center's Portrait Orientation Lock for a firm screen lock.

Take and save a photo

  1. Live shot captures the video feed at its actual dimensions. The 3- or 10-second timer is available here.
  2. Full photo, the default, opens the native iPhone camera for a better-quality source. Accept the photo, then fine-tune its look in LeLuma. Live LeLuma effects are applied after returning from that camera sheet.
  3. Tap Save photo → Share / Save Image → Save Image to save to Photos. If unavailable, choose Open photo to save manually and touch and hold the image.
  4. Keep an unfiltered original too saves a separate uncropped original.
Quality: Preview size never sets saved-photo size. Full frame preserves source dimensions; portrait and landscape deliberately crop edges. PNG avoids additional lossy encoding. Filtered copies do not retain all native RAW, HDR, depth, Live Photo, metadata, and color-processing features. Keep your original. Very large images may exceed device memory; the app reports a failure instead of silently shrinking the export.

Offline and privacy

Camera, filters, favorites, and export work locally while the cached files remain available. iOS may remove website data, requiring another online launch and potentially clearing favorites. Download iCloud-only photos before importing offline. Photos and edits are held in memory: save them before closing.

No accounts, analytics, or photo uploads. Skin looks soften skin-like colors; Definition increases local contrast and sharpening around existing features. It does not reshape faces or bodies.

The shipping shader, scheduling, favorites, export, and offline paths have automated checks. Physical iPhone frame rate and Safari behavior remain unverified. See TEST-REPORT.md for the precise evidence.
